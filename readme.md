# Multi-Agent Research Assistant Architecture

A fully autonomous AI system that thinks, searches, reads, and writes on its own. Instead of a single AI answering questions from memory, a team of specialized intelligent agents collaborates to produce a professional research report on any given topic.

---

## System Workflow & Agent Roles

1. **Search Agent**
   * Accesses the live internet to find the most relevant and recent sources.

2. **Reader Agent**
   * Dives deep into the gathered sources, scraping and extracting meaningful content.

3. **Writer Agent**
   * Takes all collected intelligence and crafts a well-structured, detailed report.

4. **Critic Agent**
   * Reviews the entire report, scores it, and provides feedback—acting like a senior researcher reviewing a junior's work.

---

## Technical Architecture & Highlights

* **Powered by LLMs:** Every single agent is driven by a Large Language Model.
* **Pipeline Integration:** Connected through LangChain's modern LCEL pipeline.
* **Shared Memory System:** Orchestrated via a shared memory architecture that allows all agents to work as one unified brain.
* **Production-Level System:** This is not a chatbot or a simple Q&A tool, but a production-grade agentic AI system—the kind of architecture top AI companies actively build and hire for.
